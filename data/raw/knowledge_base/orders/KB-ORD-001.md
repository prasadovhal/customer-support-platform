# Order Cancellation Policy

**Version 2.0 — Effective January 1, 2026**

## Overview

Customers may cancel orders subject to the eligibility rules below. Order cancellation eligibility depends on the current order status.

## Cancellation Window

Orders can be cancelled **within 1 hour** of placement if the order status is still "placed" or "confirmed."

After 1 hour, orders may still be cancellable if they have not yet entered the "processing" or "shipped" status. Once an order is in processing, cancellation is not guaranteed.

## Cancellation by Order Status

| Order Status | Cancellation Eligible? |
|-------------|----------------------|
| Placed | Yes — immediately |
| Confirmed | Yes — within 1 hour |
| Processing | Possibly — contact support immediately |
| Shipped | No — must return after delivery |
| Out for delivery | No — must return after delivery |
| Delivered | No — must initiate return |
| Delayed | Yes — contact support |
| Cancelled | Already cancelled |

## How to Cancel

**Self-service (within 1 hour):**
1. Go to Account > Order History.
2. Select the order.
3. Click "Cancel Order."
4. Confirm cancellation.

**After 1 hour (if still in confirmed/processing):**
Contact support immediately via live chat or phone for fastest response. Email may not be fast enough if the order is approaching shipment.

## Refund After Cancellation

Full refund is issued for all eligible cancellations. See KB-REF-003 for cancellation refund timelines.

## Non-Cancellable Orders

The following order types cannot be cancelled once placed:

- Custom-configured products
- Digital goods (software keys, downloads)
- Pre-orders that have already shipped
- Flash sale items (clearly marked at purchase)

## Partial Cancellation

For multi-item orders, individual items may be cancelled if they have not yet been packed separately. This requires contacting support directly.
