# Return Shipping Instructions

## Overview

This article explains how to package and ship items back to Acme Store when initiating a return.

## Step-by-Step Return Shipping Guide

### Step 1: Initiate Your Return

Before shipping anything:

1. Log in to your Acme Store account.
2. Go to **Orders** > Select the order > **Return Item**.
3. Choose the reason for return.
4. Confirm the return to receive your **Return Merchandise Authorization (RMA) number**.

Returns without an RMA number cannot be accepted at our warehouse.

### Step 2: Prepare the Package

- Use the **original packaging** if available. This protects the item during transit.
- If original packaging is unavailable, use a sturdy box with adequate padding.
- Remove or cover any previous shipping labels.
- Include the **RMA slip** (printed or written) inside the package.
- Do not include any items not part of the return.

### Step 3: Attach the Return Label

Acme Store provides a **prepaid return shipping label** for:

- Defective or damaged items (always free).
- Items incorrectly shipped.
- Returns under active promotional "free returns" offers.

For **change-of-mind returns**, return shipping costs are the customer's responsibility unless otherwise stated.

### Step 4: Drop Off the Package

- Use the carrier specified on the return label (UPS, FedEx, or USPS).
- Retain the **drop-off receipt** as proof of return shipment.
- Track the return using the tracking number on your label.

## Return Shipping Timeframes

| Event | Timeframe |
|-------|-----------|
| RMA approval | Immediate (automated) |
| Return label emailed | Within 30 minutes |
| Processing after receipt | 3-5 business days |
| Refund initiated | After processing completion |

## International Returns

For international returns, customs documentation is required. Contact support for a pre-filled customs form. International return shipping costs are not covered unless the item is defective.
