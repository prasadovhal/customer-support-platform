# Non-Returnable Items and Return Exceptions

## Overview

While Acme Store strives to offer a generous return policy, certain product categories are excluded from returns for hygiene, safety, or licensing reasons.

## Non-Returnable Categories

The following items cannot be returned under any circumstances:

- **Digital downloads and software licenses** — Once a license key is activated or a digital file is downloaded, returns are not accepted.
- **Consumable items** — Batteries, ink cartridges, and single-use accessories once opened.
- **Personal hygiene products** — Earbuds, in-ear monitors, and other products that contact the body, once unsealed.
- **Custom or personalized items** — Products engraved, monogrammed, or built to customer specification.
- **Hazardous materials** — Cleaning chemicals, certain batteries, and goods requiring special disposal.
- **Gift cards and prepaid vouchers** — Once purchased, these have no cash return value.

## Partially Restricted Categories

| Category | Condition |
|----------|-----------|
| Opened software | Only if media is defective |
| Perishables | Not applicable (not sold by Acme Store) |
| Security-sealed products | Must be unopened |

## Exceptions That Override Non-Returnable Status

Even for non-returnable items, Acme Store will accept returns if:

1. The product arrived **damaged or defective** (see KB-RET-003).
2. The product does **not match the description** on the product page.
3. The wrong item was shipped.
4. A **safety recall** has been issued by the manufacturer.

## How to Request an Exception

Contact support at returns@acmestore.com with:

- Order number
- Photo evidence of the issue
- Brief description of the defect or discrepancy

Exceptions are reviewed within 2 business days. Approved exceptions receive a prepaid return shipping label.
