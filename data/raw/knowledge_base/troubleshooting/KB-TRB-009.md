# Gaming Console and Peripheral Troubleshooting

## Overview

This article covers troubleshooting for gaming controllers, headsets, keyboards, mice, and other gaming peripherals sold by Acme Store.

## Gaming Controller Not Connecting

### Wired Controller

1. Try a different USB cable or USB port.
2. Ensure the game console/PC recognizes the controller: check Device Manager (Windows) or System Information (Mac).
3. Update the controller firmware via the manufacturer's companion app.

### Wireless Controller

1. Reset the controller: hold the reset button (usually a small pinhole on the back) for 5 seconds.
2. Re-pair: hold the pairing button and pair from the console/PC Bluetooth settings.
3. Check battery level — a low battery may cause connection issues.

## Controller Input Lag

1. Use a wired connection when possible — Bluetooth adds latency.
2. Ensure no other Bluetooth devices are interfering.
3. Update controller firmware.
4. Reduce wireless distance between controller and receiver.

## Gaming Keyboard / Mouse Not Working

1. Try a different USB port.
2. Uninstall and reinstall the driver via Device Manager.
3. Test on a different computer to isolate whether it's a device or software issue.
4. Check if RGB software conflicts — disable startup applications one by one.

## Gaming Headset Audio Issues

See KB-TRB-006 for audio troubleshooting. Gaming headset-specific:

1. Ensure 3.5mm combo plug is inserted into the gaming headset jack (not separate mic/headphone ports).
2. For USB headsets, check the audio output selection.
3. Adjust in-game audio settings — some games require manual headset selection.

## Controller Stick Drift

Stick drift (joystick registering movement when not touched) is a common hardware issue:

1. Clean around the stick base with compressed air.
2. Adjust dead zone settings in the game or console settings.
3. If under warranty, file a warranty claim — stick drift caused by manufacturing defect is covered.
