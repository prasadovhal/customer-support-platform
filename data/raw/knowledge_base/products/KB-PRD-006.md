# Networking Equipment — Routers, Mesh Systems, and Switches

## Overview

Acme Store carries routers, mesh Wi-Fi systems, switches, and networking accessories suitable for home, small business, and enterprise environments.

## Routers

### Wi-Fi Standards

| Standard | Max Speed | Best Range | Released |
|----------|-----------|-----------|---------|
| Wi-Fi 5 (802.11ac) | 3.5 Gbps | Medium | 2013 |
| Wi-Fi 6 (802.11ax) | 9.6 Gbps | Good | 2019 |
| Wi-Fi 6E | 9.6 Gbps | Better (6 GHz band) | 2021 |
| Wi-Fi 7 (802.11be) | 46 Gbps | Best | 2024 |

For most home users, Wi-Fi 6 provides excellent performance and compatibility.

### Single-Router vs. Mesh System

| Scenario | Recommendation |
|----------|---------------|
| Small apartment (<1,000 sq ft) | Single router |
| Medium home (1,000–3,000 sq ft) | Single router with Wi-Fi 6 |
| Large home (3,000+ sq ft) or multi-story | Mesh system |
| Dead spots in existing setup | Range extender or additional mesh node |

## Mesh Wi-Fi Systems

Mesh systems use multiple nodes to create a seamless, whole-home Wi-Fi network.

Key advantages:
- No dead zones.
- Devices auto-connect to the strongest node.
- Centralized management via app.

Popular systems carried by Acme Store include tri-band mesh units for 100+ device homes.

## Network Switches

For wired Ethernet connections:

| Type | Use Case |
|------|----------|
| Unmanaged switch | Simple plug-and-play for home/small office |
| Managed switch | VLAN, QoS, monitoring for businesses |
| PoE switch | Powers IP cameras, VoIP phones, access points via Ethernet |

## Business Networking

For business-grade networking:

- Access points with centralized management.
- Security-focused routers with firewall and VPN.
- Business accounts receive volume discounts (see KB-ORD-004).
