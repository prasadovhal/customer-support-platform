# Acme Store — Data Foundation

**SYNTHETIC DATA ONLY — No real personal information is contained in any dataset.**

---

## What Is Acme Store?

Acme Store is a fictional e-commerce company used as the domain for the **Enterprise Customer Support AI/ML Platform**. It sells consumer electronics, laptops, smartphones, tablets, accessories, audio, home appliances, wearables, networking equipment, and gaming peripherals.

All customers, orders, products, tickets, and conversations are synthetically generated and do not represent any real individuals or transactions.

## Data Architecture

```
Knowledge Articles (Markdown, 90 files, 10 categories)
         |
         v
  [RAG pipeline: chunking, embedding, indexing]
         |
         v
    Vector Database
         (populated at runtime)

Customers ────────┐
Products  ─────────┤
Orders    ─────────┼──> PostgreSQL (runtime)
Tickets   ─────────┤
Conversations  ────┘

FAQ Questions  ──────> Evaluation
Golden QA (70) ──────> Evaluation (fully hand-crafted)
Retrieval Eval ──────> RAG Benchmarking
Agent Eval     ──────> Agent Benchmarking
Classification ──────> Triage Model Benchmarking
```

## How to Regenerate Data

```bash
# Default seed (42)
python scripts/generate_all_data.py

# Custom seed
python scripts/generate_all_data.py --seed 123
```

Generation takes ~5–15 seconds on a modern machine.

**Note:** Knowledge base articles are hand-authored and not regenerated by this script.

## How to Validate Data

```bash
# Run all validators
python scripts/validate_all.py

# Individual validators
python scripts/validate_customers.py
python scripts/validate_products.py
python scripts/validate_orders.py
python scripts/validate_tickets.py
```

## How to Load PostgreSQL

```bash
# 1. Apply schema
psql -d acmestore -f data/database/schema.sql

# 2. Load CSV data
psql -d acmestore -c "\COPY customers FROM 'data/structured/customers/customers.csv' CSV HEADER"
psql -d acmestore -c "\COPY products FROM 'data/structured/products/products.csv' CSV HEADER"
psql -d acmestore -c "\COPY orders FROM 'data/structured/orders/orders.csv' CSV HEADER"
psql -d acmestore -c "\COPY support_tickets FROM 'data/structured/tickets/support_tickets.csv' CSV HEADER"
```

See `database/README.md` for full instructions.

## Dataset Limitations

- All data is synthetically generated — it does not capture the full complexity of real enterprise support scenarios.
- Product names, prices, and descriptions are fictional; they may not reflect realistic market values.
- Conversation quality varies — template-based generation limits linguistic diversity compared to real dialogues.
- Evaluation datasets contain template-based entries beyond the 70 hand-crafted golden QA pairs.
- Knowledge base articles are representative but do not cover every possible support scenario.

---

## Synthetic Data Disclaimer

> All customers, email addresses, phone numbers, order details, and ticket messages in this dataset are **entirely synthetic**. They were generated using a fixed random seed (42) for reproducibility. Any resemblance to real persons, transactions, or events is purely coincidental.
